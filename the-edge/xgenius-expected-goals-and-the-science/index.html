xGenius

Expected goals, explained from the ground up for football fans.

by James Tippett · 2024

Share on X

James Tippett's second book on expected goals picks up where his first one left off — less "what is xG" and more "how is it actually built, and how do clubs use it once they have it." If the first book was the pitch for the metric, this one is closer to the mechanics underneath it.

The honest recommendation here: read Tippett's first book on the subject before this one. This one assumes you're already sold on the concept and want to go a layer deeper, not a persuasive case for xG from scratch.

Tippett spends real time on the parts of xG modeling that don't make it into popular explainers — how shot location data actually gets collected and cleaned, where model builders have to make judgment calls that quietly shape the output, and why two clubs' in-house xG models can disagree meaningfully on the same shot. That's the layer most journalism about expected goals skips entirely.

Key ideas

  • Every xG number is really a stack of modeling choices wearing a single decimal point.
  • The book picks up where The Expected Goals Philosophy left off — less "what is xG" and more how it's actually built and used inside clubs.
  • Two clubs' in-house xG models can disagree meaningfully on the same shot, because model builders make judgment calls that quietly shape the output.
  • Read The Expected Goals Philosophy first if you haven't — this assumes you're already sold on the concept and want to go a layer deeper.
Worth it if

you enjoyed the first book and want more of the same author’s thinking, taken further.
